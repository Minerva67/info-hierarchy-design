# 可视化模式库（附实现要点）

## 1. 连接条形漏斗（首选）
- 结构：`grid-template-columns: 230px 440px 1fr`；左边是编号徽章 + 环节名，中间是比例条（底槽为纸色，填充为品牌色），右边是痛点（粗体）+ 大数字（60px）+ 标签 +「行业基准」小胶囊。
- 起点环节如果没有数据，画一条虚线空条（不写解释文字）；终点「有效商机」画一个黄色圆，里面写「?」。
- 填充颜色：起点用墨黑，中间用门黄，最大漏点用橙色（全页唯一）。
- 条宽 = 该环节的比例（例：到场 52%、留存 15%）。条宽低于最小宽度时用圆点，标签放在条外。

## 2. 桑基流失图（数据冲击力最强，适合深色）
- 主流量用门黄，从左往右；每个节点向下分出一股流失带（一般流失用灰，最大流失用橙）。
- 带子用三次贝塞尔：`M x0 a0 C xm a0 xm a1 x1 a1 L x1 b1 C xm b1 xm b0 x0 b0 Z`。
- 标注放在带子末端的空白处。先算清贝塞尔扫过的区域，避免标签压在带子上或撞到图例。

## 3. Before / After 卡（方案段首选）
- 卡片顶部：环节编号 + 环节名（灰）+ 痛点（大字）。
- 中部：灰色圆（220px）放现状数字，圆旁边或圆下写标签；没有数字时放短词（如「缺少 / 曝光渠道」）。右侧是橙色竖线 + 方案名（粗）+ 一句说明。
- 底部：黄色长条，左写「结果」，右边是结果大字。
- 需要证据时（logo 墙、合作方），放进同一张卡，在方案和结果之间。

## 4. 五栏数据表（报刊）
- 列 = 环节，行 = 环节名 / 卡在哪 / 行业基准。栏间 1.5px 竖线，用 `minmax(0,1fr)` 防止撑破；长数字缩到 42px。

## 5. 对账单（打字机）
- 一张小票：每行写「环节 …… 数字」（点线引导），下面一行小字写痛点；合计行写「有效商机 ?」；底边用 SVG 锯齿。

## 6. 气泡（刊物，备选）
- 圆面积 ∝ 比例，沿一条轨道线排开，漏点编号落在两圆之间的轨道上。圆不能叠在一起；标签统一放在圆下方。

## 通用
- 一张图只回答一个问题。图下最多一行注释。
- 强调色全页只用一处。
- 编号体系全文统一（01–05），诊断和方案共用。
