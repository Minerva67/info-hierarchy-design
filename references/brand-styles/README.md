# 品牌设计语言库（14 家风格参考）

从 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)（MIT）里 84 个品牌的 DESIGN.md 中，筛出 14 家，各整理成一套风格参考。每家目录里有 `README.md`（中文摘要 + 英文原文分析）和 `tokens.json`（色板、字阶、间距、圆角；商用字体后面跟 Google 替代字体）。

**用法边界**：这些是非官方的风格参考，用来学设计语言（配色关系、字阶、圆角、版式节奏），**不放对方 logo、不冒用品牌**。用在自己的物料上时只借「结构和手法」，颜色一律换回你自己的品牌色（例：Mastercard 的大圆角和轨道线 × 你的品牌色）。
